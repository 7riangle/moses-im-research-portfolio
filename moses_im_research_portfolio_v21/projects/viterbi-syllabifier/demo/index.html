Inferred syllable roles.

O = Onset  ·  N = Nucleus  ·  C = Coda. These are the toy HMM's predictions, not verified syllable boundaries.

Dynamic programming

Log-score lattice.

Each column is an observation; each row is a possible state. The highlighted cell at each step belongs to the final best Viterbi path. Darker cells represent relatively higher accumulated log-scores within this sequence.

Values are cumulative log-scores, not probabilities. −∞ indicates an impossible or heavily penalised path in the source implementation.
Run the Python HMM in your browser

Load the Python HMM and Viterbi implementation from this portfolio into Pyodide, execute the Python HMM implementation in your browser, and display its output in the same lattice view. An internet connection is needed for Pyodide's first load; no input leaves your browser.

About the model

The original model uses hand-set transition and emission scores, rather than parameters learned from annotated speech. It may return unexpected labellings, especially near word boundaries or with ambiguous/unseen phones. Those outcomes are informative about the toy model's assumptions.

English uses ARPAbet-style phoneme tokens from the source inventory; Korean decomposes precomposed Hangul into jamo. Original repository
