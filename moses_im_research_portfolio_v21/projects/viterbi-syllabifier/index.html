Can a model find the structure of a syllable?

A small Hidden Markov Model (HMM) with Viterbi decoding that assigns onset, nucleus, and coda states to sequences of English phones or Korean Hangul jamo.

01 / Idea

From a string of sounds to a structural hypothesis.

A syllable has internal organisation, but finding it automatically is not always straightforward. I explored this as a sequence labelling problem: given a sequence of phones or jamo, can a small probabilistic model choose a plausible series of Onset, Nucleus and Coda states?

The Viterbi algorithm searches across possible state sequences and selects the highest-scoring path, taking both transition preferences and segment-state compatibility into account.

02 / Approach

A minimal probabilistic decoder.

  1. Represent a phoneme or Hangul-jamo sequence as a list of observations.
  2. Apply hand-specified HMM start, transition and emission preferences.
  3. Compute cumulative log-scores with Viterbi dynamic programming.
  4. Trace back the best O/N/C state path and visualise the score lattice.

03 / Implementation

Making the lattice visible.

The original Python project includes a small language-independent Viterbi implementation and language-specific emission/transition rules. English expects ARPAbet-style tokens; the Korean example first decomposes Hangul syllables into onset, vowel and optional final jamo.

On this page the instant demo is a direct browser adaptation of the source algorithm. It displays both the selected state sequence and the underlying dynamic-programming score table. An optional Python execution mode uses Pyodide to run the source-derived HMM implementation locally in the browser.

Interpret results cautiously. The transition and emission scores are hand-crafted, not learned from labelled syllables. The selected path is this model's preferred path, not ground-truth syllabification. Even the README's sample result for strand differs from the current decoder's actual final state.
04 / Source

Code & limitations.

The implementation is based on the original GitHub repository. The accompanying notes document the model's deliberately simplified phonotactic assumptions and possible extensions.

This is a teaching-oriented side project in probabilistic modelling, not a production-grade speech recogniser or a syllabifier trained on annotated data.
