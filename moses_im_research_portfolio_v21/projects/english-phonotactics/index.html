01 / Idea

Syllables are not just random sounds.

English consonant clusters are constrained. One influential simplification is the Sonority Sequencing Principle: sonority tends to rise towards the vowel nucleus and fall away from it.

I wrote a small Python generator that builds candidate syllables and uses a hand-crafted sonority scale to choose consonant sequences that follow this directional pattern. The program prints its generated IPA-like strings in a terminal.

Scope. This is a toy generator, not a complete grammar of Received Pronunciation. A rising or falling sonority profile does not guarantee that a cluster occurs in real English.
02 / How it works

Constructing a syllable.

  1. Choose a target onset length and consonants whose sonority rises from left to right.
  2. Choose one vowel from the project's hand-made inventory as the nucleus.
  3. Build an optional coda whose sonority falls away from the vowel.
  4. Join the pieces into a candidate and repeat for a new random example.

03 / Implementation

From Python terminal to browser.

The original script is a pure-Python project using only the standard random module. It chooses segment sequences, applies simple onset/coda sonority conditions, and prints generated outputs.

This website includes a faithful JavaScript adaptation for an instant, offline-capable demonstration. The advanced option also runs a source-derived Python implementation directly in your browser through Pyodide, without sending inputs to a Python server.

The original code retains its hand-written segment inventory and stochastic stopping rule. Some generated items may not be attested English syllables; this is a modelling limitation, not evidence that the language accepts them.
