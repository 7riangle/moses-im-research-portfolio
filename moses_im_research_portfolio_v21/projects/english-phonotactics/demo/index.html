Live demonstration · English phonotactics

A syllable generator.

Generate random onset–nucleus–coda sequences constrained by a simplified sonority scale. The result is a candidate sound sequence, not necessarily an English word.

Generated locally with a browser port of the original Python rules.

Output

Generated candidates.

Run the Python algorithm in your browser

This mode downloads Pyodide (a browser-based Python interpreter) and executes a source-derived Python implementation of the generator locally in your browser. The first load needs an internet connection and may take a moment; no inputs or results are uploaded.

What you're seeing

The generator first selects an optional onset with rising sonority, then a vowel nucleus, then an optional coda with falling sonority. It uses a randomly chosen target cluster length and may stop early. The inventory is deliberately simplified and occasionally produces unattested clusters.

The visual display separates the constituent parts; the terminal view reproduces the style of output from the Python script. View the project source
